# Bundled result files

These are the compact outputs used to make the manuscript tables and figures. They are snapshots, not generated by the
smoke test. Files with one record per concept or one record per run retain the original experiment granularity; aggregate
scripts in the corresponding `experiments/` directory show how to summarize them.

No checkpoint, image dataset, embedding cache, or training log is included. A clean rerun requires the data and model
artifacts described in `../data/README.md`.
